# PDF Studio

GitHub Pagesで公開できる、ブラウザ内処理型のPDF編集ツールです。

## 公開手順
1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** で **Deploy from a branch** を選択します。
3. Branch を `main)、フォルダを `/(root)` にして Save します。
4. 数分後、表示された Pages URL にアクセスします。

## 主な機能
- 複数PDFの読み込みとページサムネイル表示
- ページ選択・回転・削除・順番反転
- ページ範囲ごとの分割、1ページずつ分割、選択ページの抽出（ZIP）
- 複数PDFの結合（ファイル順は↑↓で変更）
- 見開きページの左右分割
- 2ページを横に並べた見開き結合
- 全画面プレビュー
- PDF / ZIP のダウンロード
- スマートフォン・PC対応

## 使用ライブラリ
- PDF.js 3.11.174
- pdf-lib 1.17.1
- JSZip 3.10.1

CDNから読み込むため、初回利用時はインターネット接続が必要です。PDFデータはブラウザ内で処理し、アプリのサーバーには送信しません。

## 注意事項
- パスワード保護されたPDFや破損したPDFは読み込めない場合があります。
- 見開き分割は各ページの中央を基準に左右を切り出します。
- 見開き結合は連続する2ページを横に配置します。ページ数が奇数の場合、最後のページの右側は空白になります。
- 用紙変換はA4/A5プリセットに対応します。
- 大容量PDFは端末のメモリによって処理できない場合があります。
